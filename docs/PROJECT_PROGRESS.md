## 🧠 Architectural Decisions Log
1. **Decision**: Python FastAPI chosen for the backend to support native Python ML/NLP tools (PyMuPDF, docx, ZIP security checks) alongside Gnani model proxies.
2. **Decision**: React + TypeScript + Vite chosen for the frontend for high-performance responsive UI, Web Audio API, and seamless animation.
3. **Decision**: Zero-Credit Mock Policy strictly enforced. All models provide full simulation fallbacks so the application is completely testable without consuming credits.
4. **Decision**: Hardware awareness for Evon v3.3: Since local RTX 3050 (6GB VRAM) cannot run a 30B LLM locally, a modular adapter pattern is used with transparent disclosure in code and documentation.
